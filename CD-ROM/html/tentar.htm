— b ) Forma las expresiones:

— a a ) Tentar el vado: sondear, probar y explorar los talentos de alguna persona o la posibilidad de algún negocio. Etim. Del lat. temptare ‘palpar, tentar, probar a hacer algo’. Cat. tentar, tentejar; fr. tenter; it. tentare.

Conjug. Presenta las siguientes formas irregulares: tiento, -as, -a, -an; tiente, -es, -e, -en; tienta (tú).
